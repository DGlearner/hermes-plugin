# 工作进展同步日报

> **填写目的：** 同步项目和工作的最新进展，及时暴露卡点与风险，明确需要的帮助和下一步安排，方便团队与管理层协调推进。
>
> **填写原则：** 围绕项目和事项填写；有变化的内容重点更新，无变化的内容简要说明。常规事项简写，关键进展、卡点和支持需求详细写。

## 二、今日重点同步

用几句话，让主管和上级快速了解当前情况。

- **关键进展：** 今天有哪些重要推进、交付或确认？
- **整体判断：** 当前是否按计划推进？是否影响关键节点？
- **主要卡点／风险：** 当前最需要关注什么？无则填写“无”。
- **需要的帮助／决策：** 需要谁在什么时间前提供什么支持？无则填写“无”。

### 日报使用约定

1. 重点写清“现在到哪一步、发生了什么变化、接下来怎么走、需要什么帮助”。
2. 没有明显进展时，说明当前等待的条件、预计反馈时间和后续安排。
3. 进度以阶段成果、剩余步骤和预计完成时间表达；需要使用百分比时，说明依据。
4. 卡点和风险尽早同步，允许暂时没有完整解决方案，先把已知情况和支持需求说清楚。
5. 紧急问题及时沟通，并在日报中补充记录。
6. 已在项目系统中维护的信息可附链接，日报提炼关键变化和需要关注的事项。
